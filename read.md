# 🎬 CineMatch – Movie Recommendation Website

## 📌 Project Description
CineMatch is a movie recommendation website developed using HTML, CSS, and JavaScript. It allows users to explore movies, search by title, filter movies by genre, view movie details, receive random recommendations, and maintain a personal watchlist.

The project demonstrates the practical application of front-end web development concepts in an interactive and responsive website.

## 🎯 Objectives
- To develop an interactive movie discovery website.
- To implement movie search and genre filtering.
- To provide random movie recommendations.
- To allow users to add and remove movies from their watchlist.
- To demonstrate HTML, CSS, and JavaScript concepts.

## 🛠️ Technologies Used
- **HTML5:** Website structure and semantic elements.
- **CSS3:** Styling, responsive layouts, transitions, and animations.
- **JavaScript:** Search, filtering, DOM manipulation, and event handling.
- **LocalStorage:** Saving watchlist data in the browser.

## ✨ Features
1. Attractive homepage with modern design.
2. Movie cards with titles, genres, release years, ratings, and descriptions.
3. Search movies by title.
4. Filter movies by genre.
5. View movie details in a dialog box.
6. Generate random movie recommendations.
7. Add or remove movies from a personal watchlist.
8. Save the watchlist using browser LocalStorage.
9. Feedback form with client-side validation.
10. Responsive design for desktop and mobile devices.
11. CSS hover effects, transitions, and animations.
12. JavaScript click, double-click, mouseover, and mousemove events.

## 🚀 How to Run the Project

1. Download or clone the project repository.
2. Open the project folder in Visual Studio Code.
3. Ensure that `index.html`, `style.css`, and `script.js` are in the same folder.
4. Open `index.html` in a web browser or use the Live Server extension.
5. Explore movies, apply genre filters, and manage your watchlist.

## 📚 Concepts Covered
- HTML headings, paragraphs, links, metadata, and semantic tags.
- CSS external stylesheets, responsive design, pseudo-classes, pseudo-elements, transitions, and animations.
- JavaScript variables, arrays, objects, functions, conditions, and event listeners.
- DOM manipulation and dynamic HTML content.
- Form validation and dialog boxes.

## 🔮 Future Enhancements

## ⚠️ Limitations
- The website uses sample movie information.
- Movie posters require an internet connection.
- The watchlist is saved locally in the user's browser.
- The feedback form demonstrates validation but does not submit data to a server.
